## 逻辑运算符

### And
```python
#and用于判断其两侧的值，是否都为True
print(True and True)     #True
print(True and False)    #False
print(False and True)    #False
print(False and False)   #False
print(8 >7and 8>7)       #True
print(8 >7and 2>3)       #False
print(2 >3 and 8>7)      #False
print(2>3and 2>3)        #False
```
```python
#and具备"逻辑短路"能力
print(False and 3 / 0)   #False
print(True and 3 / 0)    #报错，因为判断了True要继续判断3/0，0不能作除数，所以报错
```
```python
#and返回的不一定是布尔值，它返回的是某个参与计算的值本身
#规则:and会先看左边，如果左边是"假"，就直接返回左边，否则返回右边
#备注:若参与and运算的值不是布尔值，那Python会自动转为布尔值，然后再进行逻辑操作
print(2 - 2 and True)   #0
print(''and True)       # 
print(True and 8 / 2)   #4.0
print(3 + 3 and 3 *4)   #12
```
### or
```python
#or用于判断其两侧，是否至少有一个为True(只要有一个是True，那就返回True)
print(True or True)   #True
print(True or False)  #True
print(False or True)  #True
print(False or False) #False
```
```python
#or同样具备逻辑短路能力
```
```python
#or返回的也不一定是布尔值，它返回的是参与计算的值本身
#规则:or会先看左边，如果左边为"真"，就直接返回左边，否则返回右边
print(7 - 2 or False)   #5
print('你好'or'Hello')   #你好
print(False or 8 / 2)   #4.0
print(2 - 2 or 3 *4     #12
```
### not
```python
#not用于取反
print(not True)    #False
print(not False)   #True
print(not 3 >2)    #False
print(not 3 < 2)   #True
```
```python
#not返回的值，一定是布尔值!

print(not 9 // 4) #False
print(not 'abc')  #False
```

## 分支

## 分支：基于**判断结果**，来决定走**哪条路径**

分支之间是**互斥**的

### 单分支

```python
if 判断条件：    #判断条件可以是关系运算。也可以是布尔值
	执行代码1
	执行代码2
#if后的执行语句必须有要空格，并且每个执行语句前的空格数相同
```

```python
age = int(input('请输入你的年龄'))
if age >= 18:
    print('你是成年人')
    print(f'你的年龄是{age}岁')
```

### 双分支

### if-else

```python
if 判断条件：
	条件成立时执行的代码1
	条件成立时执行的代码2
else:
	条件不成立时执行的代码1
	条件不成立时执行的代码2
```

```python
age = int(input('请输入你的年龄'))
if age >= 18:
    print('你是成年人')
    print(f'你的年龄是{age}岁')
else:
    print('你是未成年人')
    print(f'你的年龄是{age}岁')
```

### 多分支

```python
if 判断条件1:
	条件1成立时执行的代码
elif 判断条件2:
	条件2成立时执行的代码
elif 判断条件3:
	条件3成立时执行的代码
else:
	上述所有条件不成立时执行的代码
```

## 循环

## while循环

```python
while 循环条件:
	条件成立时执行的操作1
	条件成立时执行的操作2
	
#循环条件为True会继续循环，为False会终止循环。
#要设计好循环条件，避免死循环。
```

```python
riddle = '从0-100中选一个数'
answer = '23'
guess = ''
print(f'问题是：{riddle}')
while guess != answer:

    guess= input('请输入答案')
    if guess == answer:
        print('回答正确')
    else:
        print('回答错误')
```

### for循环

```python
for 当前取出的值 in 可迭代对象:
	要执行的循环操作1
	要执行的循环操作2
#可迭代对象中的元素有多少个，循环就执行多少次。
#只要不在循环内部修改可迭代对象，for 循环通常是不会出现死循环的。
```

```python
#数字循环
#使用for循环遍历range()所指定的数字范围
for n in range(1,4)
	print('你好',n)
#你好1
#你好2
#你好3

字符串循环
#使用for循环遍历字符串
for m in 'abcd'
	print(m)
#a
#b
#c
```

for循环还能遍历很多我们没有讲到的东西，比如:元组、列表、对象...

```python
#加密代码
text = input('请输入要加密的文字：')
secret = ''
for t in text:
    secret += chr(ord(t) + 1)
print(f'加密后的文字是:{secret}')

#解密代码
secret = input('请输入要解密的文字：')
text = ''
for s in secret:
    text += chr(ord(s) - 1)
print(f'经过解密的文字是：:{text}')
```
