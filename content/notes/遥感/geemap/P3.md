## 影像可视化
1. 创建地图（参数）   Map = geemap.Map(属性)
2. 导入影像     image = ee.Image(’影像’)
3. 可视化    vis_params = \{属性\}   #一个字典，属性应 该是\{’key1 ‘：value1，’key2’：value2\}
4. 增加底图    Map.addLayer(image,vis_params,’底图名称’)
5. 显示地图    Map
```python
Map = geemap.Map(center=[21.79, 70.87], zoom=3)
image = ee.Image('USGS/SRTMGL1_003')
Map.addLayer(image, {'min':0,'max':6000,'palette':'terrain'}, 'SRTM')
Map
```
### 可视化内容
```python
'min' : 0,     #最小值
'max' : 6000,     #最大值
'palette' : ['006633','E5FFCC','blue','red']    #调色盘，从左到右一次是从小到大

'palette': 'terrain'    #调用geemap内置调色盘
```

## 筛选影像
两种写法
- .filterDate（‘2020-01-01’，‘2022-01-01’） #影像日期范围，左闭右开
- .filterBounds(Map.user_roi)   #影像空间范围，可以输入ROI，可以导入，可以在图上框选
- .filter([ee.Filter.lt](http://ee.filter.lt/)('CLOUDY_PIXEL_PERCENTAGE', 5))   #云量小于5%

### 筛选矢量数据集
```python
Map = geemap.Map()
states = ee.FeatureCollection('TIGER/2018/States')
feat = states.filter(ee.Filter.eq('NAME', 'Texas'))  #筛选属性表中字段
Map.addLayer(feat, {}, 'Texas')
```
