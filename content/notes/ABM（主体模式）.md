# ABM（主体模式）

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-17 08:27:05.955

---

理解土地利用变化的宏观决策机制，从**"微观主体行为"**到**"宏观土地格局"**的模拟方法，深入解析土地利用变化的底层逻辑，是LUCC微观机制研究的前沿方向。
前面的 CA、CLUE 模型，都是从宏观的格局、规律出发，模拟土地利用变化，而 ABM 模型，是从微观的 "人" 的决策出发，模拟不同主体的行为如何导致宏观的土地利用格局变化，能回答 "土地利用变化，到底是哪些人的决策导致的" 这个核心问题。
# 概念
1. **主体（Agent）**：是模型中自主决策的基本单元，对应土地利用系统中，做出土地利用决策的人或组织，是 ABM 模型的核心；
2. **环境**：是主体所处的空间与社会环境，包括土地的自然属性（高程、坡度、土壤）、空间区位、政策约束、市场环境等，是主体决策的约束条件；
3. **行为规则**：是主体做出决策的逻辑，也就是 "主体在什么环境下，会做出什么样的土地利用决策"，比如农户在什么情况下会把耕地撂荒，开发商在什么情况下会拿地开发；
4. **相互作用**：包括主体之间的相互作用（比如农户之间的模仿、政府和开发商的博弈），以及主体和环境的相互作用（主体的决策改变土地利用格局，土地格局的变化又反过来影响主体的后续决策）。
# 核心主体
土地利用系统中，最核心的决策主体有三类，也是 ABM 模型中最常用的主体：
1. **农户主体**：是农业用地变化的核心决策者，决定了耕地的种植、撂荒、流转，林地、草地的开发与保护，是乡村地区土地利用变化的核心主体；
2. **开发商主体**：是城市建设用地扩张的核心决策者，决定了住宅、商业、工业用地的开发，是城市土地利用变化的核心主体；
3. **政府主体**：是土地利用的管控者，通过政策、规划、土地供应，约束和引导其他主体的决策，决定了土地利用变化的边界和规则，比如划定生态保护红线、出让建设用地、制定耕地保护政策。
# 核心逻辑
ABM 模型的核心魅力，就是**涌现性**：简单的微观主体行为规则，通过相互作用，会涌现出复杂的宏观土地利用格局，而这个宏观格局，和我们实际观测到的土地利用变化完全一致。
- 通俗解释：我们不需要提前设定城市扩张的宏观规律，只需要设定好农户、开发商、政府的微观决策规则，让他们在模型中自主互动，最终就会涌现出和现实一致的城市扩张格局，完美还原土地利用变化的底层机制。
# 构建步骤
ABM 模型没有通用的标准化软件，一般需要用编程工具实现，优先选择 NetLogo 软件，专门为 ABM 模型开发，可视化操作，不需要复杂的编程，入门门槛低。
- 零基础通用构建步骤：
	1. **明确研究问题与系统边界**
		- 确定研究的核心问题，比如 "农户决策如何影响耕地撂荒""开发商与政府的博弈如何影响城市扩张"；
		- 确定系统的边界，包括空间范围、时间尺度、核心主体类型，不要盲目加入太多主体，导致模型过于复杂。
	2. **主体特征与行为规则设定**
		- 这是 ABM 模型的核心，需要基于调研、文献、统计数据，设定主体的特征和行为规则。比如农户主体，特征包括家庭人口、收入、耕地面积、务农意愿；行为规则包括 "当务农收入低于外出务工收入时，有概率把耕地撂荒或流转"。
		- 行为规则的设定，必须有现实依据，不能凭空想象，一般通过实地调研、问卷调查、计量模型回归得到。
	3. **环境与空间数据加载**
		- 把研究区的土地利用数据、高程、坡度、交通路网、行政边界等空间数据，加载到模型中，构建主体所处的空间环境；
		- 设定政策约束环境，比如生态保护红线、耕地保护政策等。
	4. **主体相互作用与模型运行逻辑设定**
		- 设定主体之间的相互作用规则，比如农户之间的信息交流、政府对开发商的土地出让、政府对农户的生态补偿；
		- 设定模型的时间步长和运行逻辑，比如每个时间步长对应现实中的 1 年，每年主体更新一次决策，土地利用格局更新一次。
	5. **模型校准、验证与敏感性分析**
		- 用历史的土地利用数据、调研数据，校准模型的参数，让模型的模拟结果和现实数据拟合；
		- 验证模型的有效性，看模型能不能还原历史的土地利用变化；
		- 做敏感性分析，看哪些参数对模型结果的影响最大。
	6. **情景模拟与结果分析**
		- 设置不同的情景，比如不同的耕地保护政策、不同的生态补偿标准、不同的土地出让政策；
		- 运行模型，对比不同情景下的土地利用格局变化，分析政策的影响效果，提出优化建议。
# 优缺点
核心优势
1. **能深入解析土地利用变化的微观机制**：从 "人" 的决策出发，解释 "为什么会发生土地利用变化"，而不是只描述 "怎么变"，能揭示宏观格局背后的底层逻辑；
2. **能模拟复杂的主体博弈与政策效应**：可以模拟不同政策下，各个主体的行为变化，以及最终的土地利用效应，非常适合政策评估，比如生态补偿政策、耕地保护政策的效果模拟；
3. **能还原系统的涌现性和不确定性**：能模拟土地利用系统的复杂动态变化，捕捉非线性、不确定性的过程，比传统的宏观模型更贴合复杂的现实系统。
核心局限
1. **入门门槛高**：需要对研究区的主体决策行为有深入的了解，需要大量的实地调研数据，同时需要一定的编程能力，对零基础不友好；
2. **参数校准难度大**：模型的参数很多，行为规则的设定有一定的主观性，校准和验证的难度大；
3. **计算量大**：当主体数量很多时，模型的运行速度很慢，不适合大尺度的模拟，一般用于县域、乡镇等小尺度的精细研究。
# 使用场景
- 乡村地区耕地利用、撂荒、流转相关的农户行为研究；
- 城市扩张中的开发商、政府、居民的博弈与决策研究；
- 生态保护政策、耕地保护政策的效果评估与优化；
- 小尺度、精细化的土地利用微观机制研究。
