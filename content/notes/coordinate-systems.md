做 GIS 第一件事就是搞清楚坐标从哪来、到哪去。这篇笔记把坐标系拆成两层来理解：**地理坐标系（GCS）**描述"点在椭球上的位置"，**投影坐标系（PCS）**描述"点在平面上的位置"。

## 两个层面：基准与投影

地理坐标系的核心是椭球模型与大地基准：

- **WGS84**：GPS 使用的全球基准，EPSG:4326，经纬度单位是"度"。
- **CGCS2000**：2000 国家大地坐标系，EPSG:4490，与 WGS84 在米级精度下可以忽略差异。
- **GCJ-02 / BD-09**：火星坐标与百度坐标，是**加密偏移**而非基准差异，国内在线地图必须处理。

投影则把椭球面摊平，必然产生变形——长度、面积、角度不可能同时保真。

## 常用投影速查

| 投影 | 特性 | 典型用途 |
| --- | --- | --- |
| 高斯克吕格（GK） | 等角横轴圆柱，6°/3° 分带 | 国内标准地形图 |
| UTM | GK 的变种，椭圆柱割椭球 | 全球军事/卫星影像 |
| Web Mercator (EPSG:3857) | 等角，面积在高纬严重失真 | 所有 Web 底图 |
| Albers | 等积圆锥 | 全国尺度土地利用制图 |

## 一个高频坑：度与米

EPSG:4326 的单位是度，直接计算距离是错的。正确做法是投影到平面坐标系再量算：

```python
from pyproj import Geod

geod = Geod(ellps="WGS84")
# 上海人民广场 → 杭州西湖
_, _, dist = geod.inv(121.4737, 31.2304, 120.1492, 30.2459)
print(f"{dist / 1000:.1f} km")  # 165.5 km
```

## 常用 EPSG 代码

- `EPSG:4326` — WGS84 经纬度
- `EPSG:4490` — CGCS2000 经纬度
- `EPSG:3857` — Web Mercator（瓦片底图）
- `EPSG:4479` — CGCS2000 地理坐标系（2000 经纬度）
- `EPSG:4526` 等 — CGCS2000 3°带高斯克吕格（按带号递增）

## 判断图层坐标系的三条经验

1. 坐标范围在 `[-180, 180] / [-90, 90]` → 大概率是经纬度（4326/4490）。
2. 坐标是 6~8 位大数字（如 `38500000, 3500000`）→ 高斯克吕格或 UTM 米制投影。
3. 国内数据叠加在线底图偏了约 500m → 大概率没做 GCJ-02 纠偏。
