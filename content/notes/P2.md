# 创建地图
## 不同绘图软件包
- Ipyleaflet
- Folium
- Plotly
- Pydeck
- KeplerGL
## 使用ipyleaflet创建底图
```python
import ipyleaflet
Map = ipyleaflet.Map()  #可以不赋值给变量，直接geemap.Map()也可以显示地图
Map                 #调用变量，显示地图
```

# 定义地图
通过不同的属性，更改地图参数
## 选择是否添加地图控件
```python
Map =geemap.Map(data_ctrl=False,toolbar_ctrl=False, draw_ctrl=False,zoom_ctrl=False,fullscreen_ctrl=False,measure_ctrl=False)
Map
```
## lite版本（无地图控件）
```python
Map = geemap.Map(lite_mode=True)
Map
```
