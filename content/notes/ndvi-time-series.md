植被指数是遥感里最古老也最常用的定量产品。但直接拿 DN 值算 NDVI 是新手最常见的错误——先把物理链条理清楚。

## 正确的计算链条

原始影像 DN 值 → **辐射定标**（转辐亮度）→ **大气校正**（转地表反射率）→ 计算指数。

NDVI 定义：

```text
NDVI = (ρ_NIR - ρ_Red) / (ρ_NIR + ρ_Red)
```

取值范围 [-1, 1]：健康植被因叶绿素强吸收红光、叶片结构强反射近红外，典型值 0.6~0.9；裸土 0.1 上下；水体为负。

## 为什么会有 EVI 和 SAVI

NDVI 的两个先天缺陷催生了改进指数：

- **高生物量区饱和**：茂密森林 NDVI 挤在 0.85 附近分不出高下 → EVI 引入蓝光波段修正大气影响、增益系数提高敏感度；
- **低植被覆盖区受土壤背景干扰**：SAVI 加上土壤调节因子 L（通常 0.5）。

```text
EVI  = 2.5 × (ρ_NIR - ρ_Red) / (ρ_NIR + 6ρ_Red - 7.5ρ_Blue)
SAVI = 1.5 × (ρ_NIR - ρ_Red) / (ρ_NIR + ρ_Red + 0.5)
```

经验法则：区域植被茂密用 EVI，干旱半干旱区用 SAVI，一般区域 NDVI 足够稳。

## 时序分析的关键：物候

单期 NDVI 说明不了太多问题，时序才能揭示物候：

1. 构建逐年/逐旬 NDVI 序列（GEE 里用 `ImageCollection` 很方便）；
2. 用谐波拟合或 SG 滤波去除云污染造成的异常值；
3. 提取物候参数：生长季开始 (SOS)、峰值 (POS)、结束 (EOS)、振幅；
4. 对比不同年份的参数变化，研究干旱、城市化对植被的影响。

## 常见坑

- 不同传感器（Landsat 8 vs Sentinel-2）波段响应函数不同，NDVI 有系统偏差，跨传感器比较要先做一致性检验；
- 山区阴影会造成 NDVI 假低值，先做地形校正（如 C 校正）；
- 混合像元在水体边缘会产出 0~0.2 的"伪植被"。
