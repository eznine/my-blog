# 变化检测

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-15 12:57:28.266

---

**常见陷阱**：
1. 把季节差当变化 → 尽量同季节影像与统一分类。
2. 边界噪声导致"建设↔非建设"反复 → 斑块阈值与一致性处理。
3. 多期轨迹类别组合爆炸（n类^k期） → 只关注关键轨迹（如涉及建设或涉及林草湿变化）。
4. 热点分析尺度随意 → 选政策相关尺度（区县/街道/1km网格）并做尺度敏感性讨论。

# 两期变化检测
**最常用的"后分类比较"**

## 原理
有 t1 与 t2 两期土地利用图。把它们叠加，每个像元/地块就有一对类别（t1类别、t2类别）：
- 若相同：未变化
- 若不同：发生了"t1→t2"的转化
这就是后分类比较。

## 优缺点
优点：
- 结果直观，可直接得到转移矩阵
- 类别含义清晰，便于政策解释
缺点：
- 两期分类误差叠加，容易产生假变化
- 边界像元噪声容易造成"虚假转移"

## 应对误差的策略
- 统一MMU与滤波
- 设定最小变化斑块阈值（过滤极小碎斑）
- 对关键变化通道（如红线内新增建设）进行抽样核查

# 指数差分/光谱变化检测
**辅助定位变化区**
常见做法：
- NDVI差分：定位植被增减
- NDBI差分：定位建成区变化
- MNDWI差分：定位水体变化
适用场景：
- 你想快速找到变化热点，再做精细分类或人工核查
- 或用于构建变化样本（正样本集中在高差分区）
注意：指数差分不能直接给出"变化类型"（只是变化强弱），常与后分类比较结合。

# 多期变化检测
**从"差分"走向"轨迹"**
当有三期及以上（如2000/2010/2020），你可以做更有价值的分析：

## 变化轨迹（trajectory）
每个像元形成一个类别序列，例如：
- 耕地 → 建设 → 建设（一次性开发）
- 林地 → 耕地 → 林地（反复变化，可能与政策/市场波动有关）
- 草地 → 裸地 → 建设（开发前扰动）
轨迹分析的价值：
- 区分"不可逆转化"（耕地→建设通常不可逆）与"可逆转化"（耕地↔林草）
- 识别政策周期影响（退耕还林在某阶段强烈）

## 变化频次（frequency）
统计像元在多期中变化了几次：
- 0次：稳定区
- 1次：一次转化区
- 多次：波动/不稳定区（常在城市边缘、工矿扰动区、季节性水体边界）

## 首次变化时间（time of first change）
某像元最早在什么时候从非建设变为建设？
这能做"扩张前沿推进图"，非常适合城市扩张研究。

# 变化热点识别
**让结果更"可决策"**
热点识别的关键是把像元级变化聚合为区域级"压力"：

## 网格聚合
每个网格统计：
- 新增建设用地面积
- 生态空间损失面积
- 红线冲突面积
得到强度图，便于识别热点带。

## 行政区聚合
输出表格与排名，便于政策建议：
- 哪些区县扩张最快
- 哪些区县生态损失最大
- 哪些区县红线压力最高

## 核密度
把新增建设斑块转点做核密度，可视化扩张"集聚核"（矢量斑块的中心点）。
