# 转移矩阵

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-16 04:42:00.207

---

**常见陷阱**：
1. 类别不一致导致假通道（园地归类不同）
2. 小斑块噪声导致大量碎小通道
3. 水体季节变化导致"水体↔裸地"异常大
4. 未做掩膜一致导致边界变化进入矩阵
对策：统一口径、阈值过滤、季节一致、做质量控制。

面积与占比只告诉你"谁增谁减"，但**不知道增的从哪里来、减的去了哪里**。
转移矩阵能回答"变化路径"，这对于：
- 城市扩张（建设用地主要占用耕地还是林地？）
- 生态保护（红线内生态空间损失来自哪类转化？）
- 碳中和（高碳储地类是否被占用？是否有生态修复转化？）
都至关重要。

# 转移矩阵的定义
设有 n 类土地类型。矩阵 (M) 的行代表 t1 类别，列代表 t2 类别：
- (M_{ij})：从 i 类转成 j 类的面积（或像元数）
- 对角线 (M_{ii})：保持不变面积
- 非对角线：发生转化的面积

最终生成的转移矩阵，有三个核心特征：
- 矩阵的对角线元素：是各地类在研究期内没有发生变化的面积；
- 矩阵的行求和：是期初各地类的总面积；
- 矩阵的列求和：是期末各地类的总面积。

# 关键指标
## 流出、流入与净变化
对某类 i：
- **总流出**：(Out_i = Σ_j M_{ij} - M_{ii})
- **总流入**：(In_i = Σ_j M_{ji} - M_{ii})
- **净变化**：(Net_i = In_i - Out_i)
解释：
- 流出大：这类被大量转走（被占用/退化）
- 流入大：这类大量新增（扩张/恢复）
- 净变化：最终增加还是减少

## 转化贡献率
例如"建设用地新增主要来源"：
- (Contribution_{i→built} = M_{i,built} / Σ_k M_{k,built})（可不含 built→built）
写作例句："新增建设用地中，耕地贡献率为X%，林地为Y%，表明城市扩张主要以占用耕地为主（或对生态空间造成显著压力）。"

## 主通道（Top flows）
### 贡献率排序法：
把所有变化类型按贡献率从高到低排序，累计贡献率达到 80% 的前几个变化类型，就是研究区变化的主通道。
### 网络分析法：
把各地类作为节点，变化类型作为边，面积作为权重，构建土地利用变化网络，找到网络中权重最高的边，就是变化的主通道。

把所有非对角线 (M_{ij}) 排序，取Top 5/10：
- 城市扩张研究中常见：耕地→建设、裸地→建设
- 生态恢复常见：耕地→林地、裸地→草地
- 生态退化常见：林地→裸地、草地→裸地（可能与采矿、火灾、过牧等）

# 空间分解
**红线内外与缓冲带**
这一步会让你的研究更有政策价值：
1. 在全域计算矩阵
2. 仅在红线内计算矩阵
3. 仅在红线外计算矩阵
4. 在红线缓冲带计算矩阵（0–1km等）
对比发现：
- 红线内是否仍发生"生态→建设"转化？规模多大？
- 红线外扩张通道是否更强？
- 缓冲带是否存在"边界挤压效应"（扩张在红线边界外侧聚集）？

# 多期转移矩阵与阶段对比
对每一阶段（2000–2010、2010–2020）分别计算转移矩阵，比较：
- **主通道**是否改变
- 建设用地扩张是否从"占用耕地"为主转向"占用裸地/存量更新"为主
- 生态恢复通道是否增强（政策效果）
这种阶段对比非常适合写"发展阶段"与"政策节点"。
