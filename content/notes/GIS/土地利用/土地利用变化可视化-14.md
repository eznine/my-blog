# 土地利用变化可视化

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-16 04:50:19.293

---

**可视化"误导风险"与规范**：
1. 色彩不一致：跨图对比困难 → 固定每类颜色
2. 类别太多：图例爆炸 → 合并小类
3. 桑基图不做阈值：不可读 → 过滤小通道
4. 变化类型图过细：噪声显眼 → 做斑块过滤与聚合
5. 不写单位与统计口径：读者无法判断规模 → 标注km²、年份、掩膜范围

**桑基图、弦图、Alluvial、时空立方体、动画、三维**

**为什么可视化不是"美工"，而是诊断工具**
在LUCC研究中，好的可视化能让读者快速理解：
- 变化规模与空间位置
- 变化通道（谁→谁）
- 变化过程（什么时候、分阶段）
- 情景差异（2030不同情景对比）

# 变化地图的经典三件套
## 变化/未变化二值图
回答：哪里总体发生变化？
适合：总体变化强度、热点区域定位。

## 变化类型图（Change type map）
显示"t1→t2"的变化类型，如耕地→建设。
适合：政策解释与路径分析。
建议：只显示最重要的几类变化，其余合并为"其他"，否则图例爆炸。

## 变化强度/密度图
把变化聚合到网格或行政区，显示强度梯度。
适合：识别扩张走廊、红线边界压力带。

# 基础统计可视化
1. **饼图 / 环形图**：用来展示土地利用现状的结构，各地类的面积占比，适合单一时相的现状结构呈现；
2. **柱状图 / 条形图**：用来对比不同时相、不同区域的各地类面积、变化率、扩张强度，是最通用的对比类图表；
3. **折线图**：用来展示长时间序列的土地利用指标变化，比如 1980-2020 年建设用地面积、多样性指数的逐年变化，展示变化趋势；
4. **雷达图**：用来展示城市扩张的方向分异、不同区域的景观指数对比，比如 8 个方向的扩张强度雷达图。

# 桑基图（Sankey）
**转移矩阵的最佳搭档**

## 回答的问题
- 哪些转移通道最大？
- 建设用地新增主要来自哪些类型？
- 生态空间损失主要流向哪里？
- 红线内外通道结构是否不同？

## 输入数据结构
把转移矩阵变成长表：
- source（t1类别）
- target（t2类别）
- value（面积）
- （可选）region（红线内/外、区县）

## 可读性技巧
- 过滤阈值：只保留Top N或超过总变化1%/2%的通道
- 颜色规则：按source着色更容易理解"谁流出"，按target着色更强调"谁流入"
- 分面：全域一张、红线内一张、红线外一张（比塞在一张里更清楚）

# 弦图（Chord）
**类别少时展示"互转关系"**
弦图更强调"互相转化"的网络感，适合类别数少、且互转重要的场景。
缺点：类别一多会乱。
建议：6类以内、且只画主要通道。

# 冲积图（Alluvial）
**多期结构演变更直观**
Alluvial可以理解为"多期桑基图"，用于展示：
- 2000→2010→2020 各类结构如何演化
- 类别如何逐步流向建设用地
- 绘图要点：每一列代表一个时相，每个色块代表一个地类，色块的高度对应面积，不同时相之间的流代表变化轨迹。
缺点：需要更清晰的聚合（通常按区域汇总，不做像元级，否则太复杂）。

# 时空立方体（Space-time cube）
**把"时间"立起来**
时空立方体适合多期热点分析：
- x-y是空间网格
- z轴是时间（年份）
每个格子在不同年份的变化强度形成柱状体。
用途：
- 看扩张热点是"持续"还是"阶段性爆发"
- 看红线边界压力带是否向外推移
注意：这种图对读者要求高，论文里要配合解释文字与二维辅助图。

# 动画与时间滑动
**LUCC过程表达的"王炸"**
如果你有多期数据（尤其逐年或每5年）：
- 动画能把扩张前沿推进表现得很直观
- 对报告或答辩非常有效
制作要点：
- 固定色带与图例（跨期一致）
- 增加关键标注（红线边界、主干道、中心城）
- 最好加一个同步的"面积曲线"小图（时间—建设用地面积）

# 三维表达
**地形约束与城市扩张（可选但很强）**
如果研究区地形起伏大：
- 在三维场景中叠加坡度与建成区扩张，可以直观解释"为什么某方向不扩张"
- 红线如果与山体/水源地相关，三维表达也更贴近生态逻辑
