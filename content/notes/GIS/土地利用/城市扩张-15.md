# 城市扩张

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-16 04:48:00.941

---

# 核心输出
城市扩张不只是"建设用地增加"，还要回答：
1. 增加在哪里？（空间前沿）
2. 以什么方式增加？（填充、边缘、跳跃）
3. 沿什么方向增加？（方向性与通道）
4. 是紧凑增长还是蔓延扩张？（碳中和非常关心）
5. 与红线/生态空间冲突在哪里？（政策含义）

# 扩张标准
**建成区/建设用地与"城市"边界：概念要说清**
- 遥感的建成区更多是"物理建成"（不透水面）
- 规划的城市建设用地是"用途边界"
两者不必完全一致，但你要在文中说明你使用哪一种表达城市扩张。

# 扩张类别
**扩张类型判别：填充式、边缘式、跳跃式**

## 定义
- **填充式（Infilling）**：在既有建成区内部空隙**补齐**
- **边缘式（Edge expansion）**：贴着既有建成区边界向**外扩**
- **跳跃式（Leapfrog）**：离开既有建成区，孤立出现**新建**成斑块

## 重要性
- 跳跃式通常导致更高的基础设施外延、通勤距离、生态破碎化 → 不利于碳中和与生态保护
- 填充式更紧凑 → 更利于低碳与减少占地

## 类型比例指标
- 各类型新增建设用地面积占比
- 各类型斑块数量占比（反映碎片化与蔓延）
常见结论写法："研究期新增建设用地以边缘扩张为主（X%），跳跃式占比为Y%，表明城市扩张呈现明显蔓延特征/或趋于紧凑化。"

# 扩张速度、强度、阶段划分
常用指标：
- 年均新增建设用地面积
- 扩张强度（可用新增面积/基期建成区面积）
- 扩张贡献（在不同区县/不同方向的贡献）
阶段划分（常见写法）：
- 2000–2010 快速扩张期
- 2010–2020 稳定扩张期或转型期
并结合政策背景解释（新区开发、产业园建设、红线划定、城市更新等）。

# 扩张方向性和空间通道
## 重心迁移（Centroid shift）
计算各期建成区重心点，连接形成迁移轨迹。
解释：
- 迁移方向与新区开发方向一致
- 迁移距离反映扩张强度与空间偏移

## 标准差椭圆（SDE）
给出扩张的主轴方向、离散程度。
解释：
- 椭圆长轴方向对应扩张主方向（沿河谷、沿交通廊道等）
- 短轴反映扩张的离散程度

## 扇区分析
以城市中心为圆心划分方位扇区，统计每扇区新增建设用地面积。
解释：
- 哪个方向扩张最强
- 与道路/开发区/地形约束的关系

# 蔓延度（Sprawl）
**蔓延的典型特征**
用来衡量城市的蔓延程度，和紧凑度相反，蔓延度越高，城市越分散、无序扩张。
- 常用公式：LSI = P / 2×√(π×A)，也就是紧凑度的倒数，数值越大，蔓延程度越高
- 建设用地碎片化增加（斑块数上升）
- 跳跃式扩张比例高
- 建成区边界更复杂（形状不规则）
- 人口/活动强度向外分散（如可获得数据）

# 紧凑度（Compactness）
**紧凑度指标**
用来衡量城市形态的紧凑程度，紧凑度越高，城市越集中，土地利用效率越高，基础设施的成本越低；紧凑度越低，城市越分散，蔓延程度越高。
- 常用公式：BCI = 2×√(π×A) / P，其中 A 是建成区的面积，P 是建成区的周长
- 解读：BCI 的取值范围是 0~1，数值越接近 1，城市形态越紧凑，越接近圆形；数值越接近 0，城市形态越分散、越不规则。

# 形态学视角
城市扩张可视为"形态生长"：
- 填充式→形态更圆润
- 跳跃式→增加飞地
- 边缘式→拉长边界
把这些与碳中和情景（紧凑发展）结合，论证非常有力。

# 城市扩张与红线的耦合诊断
可以输出三类图表：
1. 新增建设用地与红线叠加图（冲突图）
2. 红线缓冲带扩张强度曲线（压力梯度）
3. 红线边界附近扩张类型构成（是否跳跃式更明显？）
常见结论：
- “红线内新增建设面积较小但并非为零，且主要集中在…区域，提示存在局部侵占风险。”
- “红线外1km缓冲带扩张强度显著高于更外圈，存在边界挤压效应。”
