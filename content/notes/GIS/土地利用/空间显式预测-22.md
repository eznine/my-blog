# 空间显式预测

> **分类**：GIS / 土地利用

> **最后修改时间**：2026-03-17 04:30:15.973

---

土地利用适宜性评价的两大核心方法，以及空间分配的核心算法，完成从 "总量预测" 到 "空间分布预测" 的关键一步，是所有空间模拟模型的基础。
# 土地利用适宜性评价
适宜性评价，就是回答 "一个像元有多大概率适合成为某种地类"，是空间分配的核心依据，两大主流方法：
## 基于统计/机器学习的概率预测法
这是目前科研中最主流、精度最高的适宜性评价方法，核心是基于历史的土地利用变化数据和驱动因子，拟合模型，预测每个像元的适宜性概率
### 二元Logistic回归法
- 核心逻辑：以 "像元是否发生了某类土地利用变化" 为因变量（比如 "是否从非建设用地转为建设用地"，是 = 1，否 = 0），以驱动因子为自变量，拟合回归模型，输出每个像元的事件发生概率，这个概率就是该像元转为建设用地的适宜性概率。
- 实操步骤：
	1. 基于历史两期土地利用数据，生成因变量：发生变化的像元赋值 1，未变化的赋值 0；
	2. 预处理驱动因子，完成空间匹配、标准化、多重共线性检验；
	3. 在 SPSS、GIS 或 Python 中拟合 Logistic 回归模型，通过显著性检验；
	4. 把模型应用到全研究区，生成每个像元的适宜性概率栅格，概率值 0-1，数值越高，适宜性越强。
- 优势：原理简单，和驱动机制分析无缝衔接，结果可解释性强；
- 局限：只能拟合线性关系，对复杂非线性关系的拟合精度有限。
### 机器学习法
- 核心逻辑：用随机森林、XGBoost 等机器学习模型，拟合驱动因子和土地利用变化之间的非线性关系，输出每个像元的适宜性概率，比 Logistic 回归的精度更高。
- 实操步骤：
	1. 同 Logistic 回归，准备好因变量和驱动因子数据集，划分训练集和测试集；
	2. 训练随机森林 / XGBoost 模型，用测试集验证模型精度（AUC 值≥0.85 为合格）；
	3. 模型应用到全研究区，生成适宜性概率栅格。
- 优势：拟合精度高，能捕捉复杂的非线性关系，不需要提前假设线性关系；
- 局限：需要做 SHAP 可解释性分析，避免黑箱问题。
## 多准则评价法(MCE)
多准则评价法（Multi-Criteria Evaluation, MCE），是基于专家经验和规划要求，给每个驱动因子赋予权重，叠加计算每个像元的适宜性得分，不需要历史变化数据，非常适合规划情景、政策约束强的适宜性评价。
1. **核心实操步骤**：
	1. 确定评价准则：选择影响土地利用适宜性的驱动因子，比如建设用地适宜性的准则：高程、坡度、到市中心的距离、到主干道的距离、人口密度等；
	2. 单因子标准化：把每个因子的数值标准化到 0-1 之间，0 代表完全不适宜，1 代表最适宜。比如坡度因子，0-2 度赋值 1，2-6 度赋值 0.7，6-15 度赋值 0.3，>15 度赋值 0；
	3. 因子赋权：给每个因子赋予权重，权重之和为 1，权重越大，代表这个因子对适宜性的影响越大。常用的赋权方法：层次分析法（AHP）、熵权法、专家打分法；
	4. 加权叠加：在 GIS 的栅格计算器中，用加权求和公式，计算每个像元的适宜性得分：适宜性得分 = Σ(因子标准化值 × 对应权重)；
	5. 生成适宜性栅格：得分 0-1，数值越高，适宜性越强。
2. **优势**：不需要历史土地利用数据，能充分结合规划要求和专家经验，灵活性强，适合政策规划类情景；
3. **局限**：权重设置有一定的主观性，需要做敏感性分析，验证权重对结果的影响。
# 空间分配核心算法
有了各地类的适宜性栅格，和总量预测的未来各地类面积，下一步就是用分配算法，把总量分配到空间上，核心是解决 "哪些像元会发生地类转换" 的问题，必须掌握 3 种核心算法：
## 硬分配法
也叫 "最高适宜性优先分配法"，是最简单、最常用的分配算法，核心逻辑是 "适宜性越高的像元，优先被分配转换"。
- 实操步骤（以建设用地扩张为例）：
	1. 确定约束条件：设置禁止转换区域，比如生态保护红线、永久基本农田内的像元，禁止转为建设用地，适宜性强制设为 0；
	2. 计算需要新增的建设用地总量：总量预测的 2030 年建设用地面积 - 2020 年现状建设用地面积；
	3. 对非建设用地的像元，按建设用地适宜性得分从高到低排序；
	4. 从最高得分的像元开始，依次把像元转为建设用地，直到新增的建设用地面积达到总量约束，停止分配；
	5. 生成 2030 年建设用地空间分布图。
- 优势：原理简单，逻辑清晰，在 GIS 中用栅格计算器 + 排序功能就能完成，可解释性强；
- 局限：没有考虑地类转换的竞争关系，适合单一地类的分配，不适合多类地类同时转换的复杂场景。
## 轮盘赌分配法
硬分配法是完全确定性的，而轮盘赌分配法引入了随机机制，在适宜性高的像元分配概率高，适宜性低的像元也有一定的分配概率，更贴合土地利用变化的随机性，是 CA 模型中最常用的分配算法。
- 核心逻辑：把每个像元的适宜性得分，转换为分配概率，像元的适宜性得分越高，在轮盘赌中被选中的概率越大，每次迭代选中适宜的像元进行转换，直到达到总量约束。
- 优势：能模拟土地利用变化的随机性，避免完全确定性的结果，更贴合实际；
- 局限：需要多次迭代运行，做蒙特卡洛模拟，降低随机误差。
## 多类别竞争分配法
当我们需要同时模拟多个地类的相互转换时，就需要多类别竞争分配法，核心是解决 "一个像元同时适合多个地类时，应该转为哪个地类" 的问题，是 CLUE-S、FLUS 等模型的核心算法。
- 核心逻辑：
	1. 为每个地类生成对应的适宜性栅格；
	2. 设置每个地类的总量约束、转换规则（比如耕地可以转建设用地，生态保护红线内的林地不能转其他地类）；
	3. 计算每个像元对每个地类的竞争优势，一般用 "适宜性得分 + 转换弹性" 来衡量；
	4. 按照竞争优势从高到低，为每个像元分配最终的地类，同时满足各地类的总量约束，直到所有地类的总量都达到预测值。
- 优势：能同时模拟多个地类的相互转换，贴合实际的土地利用变化过程，是目前主流模型的核心算法；
- 局限：逻辑相对复杂，需要借助专用模型软件完成。
