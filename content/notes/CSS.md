# 引入方式
## 内联（行内）样式<br>
要使用内联样式，你需要在相关的标签内使用样式（style）属性。<br>Style 属性可以包含任何 CSS 属性
![](/uploads/20260901-665353.png)
## 内部样式
当单个文档需要特殊的样式时，就应该使用内部样式表。你可以使用 \<style\> 标签在文档头部定义内部样式表
![](/uploads/20260901-555a22.png)
## 外部样式（推荐）
当样式需要应用于很多页面时，外部样式表将是理想的选择。在使用外部样式表的情况下，你可以通过改变一个文件来改变整个站点的外观。每个页面使用 \<link\> 标签链接到样式表。 \<link\> 标签在（文档的）头部
![](/uploads/20260901-5f32e9.png)
# 选择器
CSS语法 规则由两个主要的部分构成：**选择器**，以及一条或多条声明（样式）
## 全局选择器
可以与任何元素匹配，优先级最低，一般做样式初始化
![](/uploads/20260901-8be385.png)
## 元素选择器
HTML文档中的元素， p、b、div、a、img、body 等。<br>标签选择器，选择的是页面上所有这种类型的标签，所以经常描述“共性”，无法描述某一个元素的“个性”
![](/uploads/20260901-d4d2d5.png)
温馨提示<br>1 所有的标签，都可以是选择器。比如ul、li、label、dt、dl、input、div等<br>2 无论这个标签藏的多深，一定能够被选择上<br>3 选择的所有，而不是一个
## 类选择器
规定用圆点 . 来定义，针对你想要的所有标签使用
![](/uploads/20260901-7b9881.png)
class属性的特点<br>1 类选择器可以被多种标签使用<br>2 类名不能以数字开头<br>3 同一个标签可以使用多个类选择器。用空格隔开
![](/uploads/20260901-f43d6b.png)
## ID选择器<br>
针对某一个特定的标签来使用，只能使用一次。 css 中的 ID选择器 以 #<br>来定义
![](/uploads/20260901-426470.png)
特别强调<br>1 ID是唯一的<br>2 ID不能以数字开头
## 合并选择器
语法： 选择器1,选择器2,...\{ \}<br>作用：提取共同的样式，减少重复代码
![](/uploads/20260901-1fe395.png)
## 选择器的优先级
CSS中,权重用数字衡量<br>元素选择器的权重为: 1<br>class选择器的权重为: 10<br>id选择器的权重为: 100<br>内联样式的权重为: 1000<br>优先级从高到低: 行内样式 \> ID选择器 \> 类选择器 \> 元素选择器
同优先级选择器，按照顺序，**覆盖**

# CSS 盒子模型(Box Model)
所有HTML元素可以看作盒子，在CSS中，"box model"这一术语是用来设计和布局时使用<br>CSS盒模型本质上是一个盒子，封装周围的HTML元素，它包括：外边距（margin），边框（border），内边距（padding），和实际内容（content）
![](/uploads/20260901-5c2dbf.png)
1 Margin(外边距) - 清除边框外的区域，外边距是透明的（两个值：第一个值上下，第二个值左右）<br>2 Border(边框) - 围绕在内边距和内容外的边框<br>3 Padding(内边距) - 清除内容周围的区域（两个值：第一个值上下，第二个值左右）<br>4 Content(内容) - 盒子的内容，显示文本和图像
或者：内外边距可写成 padding-left：50px   margin-top：100px…….

# 弹性盒模型（flex box）
## 定义
弹性盒子是 CSS3 的一种新的布局模式<br>CSS3 弹性盒是一种当页面需要适应不同的屏幕大小以及设备类型时确保元素拥有恰当的行为的布局方式<br>引入弹性盒布局模型的目的是提供一种更加有效的方式来对一个容器中的子元素进行排列、对齐和分配空白空间

**CSS3弹性盒内容**<br>弹性盒子由弹性容器(Flex container)和弹性子元素(Flex item)组成<br>弹性容器通过设置 display 属性的值为 flex 将其定义为弹性容器<br>弹性容器内包含了一个或多个弹性子元素

弹性容器外及弹性子元素内是正常渲染的。弹性盒子只定义了弹性子元素如何在弹性容器内布局
