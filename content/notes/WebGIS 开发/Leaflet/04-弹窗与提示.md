## 二、Popup：详情面板

```js
// ① bindPopup：绑定后点击要素自动弹出（最常用）
marker.bindPopup('<b>武汉站</b><br>京广铁路枢纽', {
  maxWidth: 300,          // 默认 300；宽内容调大
  minWidth: 120,
  autoPan: true,          // 打开时自动平移地图确保可见
  closeButton: true,
  autoClose: true,        // 打开新的关掉旧的（默认 true）
  className: 'my-popup',  // 挂 CSS 类（定制样式：圆角/主题色）
});

// ② 手动开关
marker.openPopup();  marker.closePopup();  map.closePopup();   // 关掉所有

// ③ 事件式打开：任意时机在任意坐标弹（不只是绑在要素上）
map.on('click', (e) => {
  L.popup().setLatLng(e.latlng)
    .setContent(`你点在：${e.latlng.lat.toFixed(5)}, ${e.latlng.lng.toFixed(5)}`)
    .openOn(map);        // openOn(map) = openOn 地图并自动管理关闭
});

// ④ 内容模板化：Popup 内容就是个 HTML 字符串——函数生成即可
function popupHtml(city) {
  return `<b>${city.name}</b><br>坐标：${city.lat.toFixed(3)}, ${city.lng.toFixed(3)}
          <br><button onclick="window.fav('${city.id}')">⭐ 收藏</button>`;
}
window.fav = (id) => alert('收藏 ' + id);   // Popup 里的按钮：全局函数 + 事件委托（无框架时的套路）
```

## 三、Tooltip：轻量提示

```js
// 悬停显示、移开消失——不需要点击的轻信息用它
marker.bindTooltip('武汉站', { direction: 'top' });   // top/bottom/left/right/auto

// 两种特殊形态：
layer.bindTooltip('常驻文字', { permanent: true });    // 常显：不需要悬停（区域标注常用）
layer.bindTooltip('跟随', { sticky: true });           // 粘随鼠标（大面要素上鼠标在哪提示在哪）

// Vector 图层的默认：悬停显示（面/线上很好用）
```

**分工口诀**：**Tooltip = 是什么（identity），Popup = 详情与操作（details & actions）**。两者可同时绑：悬停看名字，点击看详情。

## 五、自测题

1. Tooltip 与 Popup 的分工口诀？
2. permanent 与 sticky 分别解决什么？
3. Popup 内容里的按钮事件，无框架时的标准做法？
4. openOn(map) 与 openLatlng 的区别？
5. "多选对比"场景 Popup 要改哪个参数？

### 参考答案

1. Tooltip 答"是什么"，Popup 给"详情与操作"。
2. permanent 免悬停常显（区域/路名标注）；sticky 提示跟随鼠标（面状要素任意位置）。
3. 内容字符串里放 onclick 调 window 上的全局函数（或委托到 document）——Popup 内容不在 React 的事件体系里。
4. openPopup 配要素；L.popup().setLatLng().openOn(map) 用于任意坐标且由 Leaflet 统一管理关闭。
5. autoClose: false（允许多个同时开）。
