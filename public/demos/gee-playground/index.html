三步上手

  1. 注册 GEE：在 code.earthengine.google.com 用 Google 账号注册（非商业用途免费），并获得一个绑定了 Earth Engine API 的 Google Cloud 项目 ID。
  2. 创建 OAuth 客户端：打开 Google Cloud Console → 凭据，选择对应项目 →「创建凭据 → OAuth 客户端 ID」→ 类型选 Web 应用，「已获授权的 JavaScript 来源」填入本页地址（如 https://eznine.xyz 或 http://localhost:3000）→ 拿到形如 xxxx.apps.googleusercontent.com 的客户端 ID。
  3. 填入设置：点右上角 ⚙，把客户端 ID 和项目 ID 填进去保存，然后点「登录 Google」完成授权即可运行代码。

内置 API

  • ee.* —— 官方 Earth Engine JavaScript 库（Image / ImageCollection / Feature / FeatureCollection / Reducer / Filter …），与 Code Editor 一致。
  • Map.addLayer(obj, visParams, name, shown) —— 图层叠加到右侧地图，支持影像、要素集、几何体。
  • Map.setCenter(lng, lat, zoom) / Map.centerObject(obj, zoom) —— 定位。
  • print(x) / print(标签, x) —— 控制台输出，EE 对象自动取值（getInfo）。
  • Export.image.toDrive({...}) 等 —— 提交导出任务（Drive / Asset），进度在「任务」面板查看，完成后去 Google Drive 下载。

快捷键

  • Ctrl+Enter（Mac：⌘+Enter）—— 运行脚本
  • Ctrl+Space —— 代码补全（基于 EE 算法目录）

已知限制

  • 登录凭据只保存在当前浏览器内存，刷新页面后需重新点一次「登录 Google」（Google 记住授权后只需一键）。
  • 客户端 ID 与项目 ID 保存在本浏览器 localStorage，只在本机使用，不会上传到博客服务器。
  • 暂不支持 ui.* 部件、Chart 图表与在线地图排版（Inspector 可用 print 代替）。
